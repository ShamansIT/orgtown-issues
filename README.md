# ToDo Row Org - Issue Tracker

Public bug-report and feature-request tracker for the [ToDo Row Org](https://marketplace.visualstudio.com/items?itemName=ToDoRow.todo-row-org) VS Code extension.

The main source repository is private (ToDo Row Org is proprietary, source-closed software - see its `LICENSE`), so this separate, public repo exists purely to give users - and their coding agents - a normal GitHub Issues flow to report a problem or request a feature, without needing access to the private source repo.

## Reporting an issue

- **As a human**: click **Issues** above → **New issue**, describe what happened (VS Code version, extension version, steps to reproduce if it's a bug).
- **As an agent working on the user's behalf** (Claude Code, Copilot, etc.): `gh issue create --repo ShamansIT/todo-row-org-issues --title "..." --body "..."` works directly - no access to the private source repo is needed to file here.

## What this repo contains

Nothing but issues (and this README). No source code, no releases, no other content.
